# cauce

Mapa 3D del relieve de la zona metropolitana de Guadalajara, con sitios de inundación, ríos y arroyos, y una simulación de lluvia.

Proyecto para el hackathon de Codex.

**Sitio:** https://codex-hackaton.vsfelix.com

## Correr local

```sh
node serve.mjs   # http://127.0.0.1:4187
```

## Pruebas

```sh
node --test tests/rain.test.mjs
```
